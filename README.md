# ReactJS Exercises

Course material for the Lexicon ReactJS exercises.

## Files

| File | Description |
| :--- | :---------- |
| `React_Exercises1.md` | The four React exercises |
| `ReactJS_Presentation.md` | The ReactJS lesson presentation |

## Exercises

1. Create a React app with Vite and change the page.
2. Integrate Tailwind CSS and style a simple page.
3. Break a UI into smaller components.
4. Pass data to components with props.

## Working locally

Follow the tasks in `React_Exercises1.md` and run the app with:

```bash
npm install
npm run dev
```
